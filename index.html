GBA Randomizer Lab

ON DEVICE
Working early build

This version performs real starter randomization for a limited set of supported retail GBA ROM revisions. It is not yet full Universal Pokémon Randomizer ZX parity. All ROM processing happens in Safari on your device.

STEP 02

Starter randomization

02

The current engine safely randomizes the three starter choices. Trainer parties, wild encounters, stats, moves, abilities, evolutions, and other advanced UPR ZX features are not implemented yet.

The app writes only the starter species fields used by the supported games. The original selected file is not changed. Keep a backup of your ROM.

STEP 03

Your randomized ROM

03

On iPhone, tap the link and choose a save location in Files if prompted. Test the output in your emulator before relying on it.

PRIVACY

Local processing

✓
  • ROM bytes are read and modified in Safari.
  • No ROM upload, server processing, or analytics code.
  • After first visit, the app shell can be cached for offline use.
  • Only specified US/EU retail revisions are currently supported. ROM hacks and unlisted revisions are rejected.
